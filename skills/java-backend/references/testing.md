# 验证

根据改动风险和项目已有测试体系选择验证，不为目录结构或简单转发代码编写只重复实现的测试。

- 领域测试覆盖状态变化、不变量和业务拒绝条件，尽量不依赖 Spring 容器。
- 应用用例测试覆盖端口交互、事务相关行为、幂等和失败路径；只模拟实际边界。
- 接口测试核对校验、协议映射、状态码与错误体。
- 改动数据库映射、消息或外部适配器时，使用项目已有的集成测试机制核对真实边界。
- 使用 MyBatis-Plus 时，针对本次改动核对 Mapper 映射、自定义 SQL、分页与插件行为；不要仅用模拟的 Mapper 证明数据库操作正确。
- 数据库变更要验证 Liquibase changelog 可从空库创建结构，并能从上一已部署版本完成升级；检查变更后的 Mapper 与查询结果。
- 多上下文变更时检查依赖方向和公开契约；若项目已有模块验证工具则运行相应检查。

运行与改动相关的测试及构建命令，报告命令和结果。缺少服务、凭据或环境而无法验证时，说明未覆盖的行为和所需条件。
