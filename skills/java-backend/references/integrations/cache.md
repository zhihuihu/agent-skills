# 缓存集成

先确认缓存目标、数据归属和允许的陈旧时间。沿用项目现有的 Spring Cache、Redis 或本地缓存方案；不因需要性能优化就默认新增 Redis。

- 为键定义命名空间、组成字段和版本方式，避免不同业务数据冲突。
- 为缓存项选择过期和失效策略；写入路径需说明何时更新或删除缓存。
- 对空值、热点键和并发加载按实际流量与项目已有机制处理。
- 缓存故障时明确读取是否可回源，以及回源对数据库的影响。
- 不把缓存当作聚合不变量的唯一保障；一致性仍由持久化与事务设计负责。

配置缓存提供者时核对项目对应版本的 [Spring Boot 缓存文档](https://docs.spring.io/spring-boot/reference/io/caching.html)。
